# AutoBudget NL

Русскоязычный планировщик расходов на личный автомобиль в Нидерландах.

Статический HTML/CSS/JavaScript. Поиск зарегистрированных моделей через публичный RDW Open Data API; расчёт расходов и сравнение сценариев в браузере.

## Локальный запуск

Откройте `dist/index.html` в браузере или запустите `python3 -m http.server 4173 --directory dist`.
Поиск RDW требует интернета. Сравнения сохраняются в localStorage этого браузера.

## Проверки

Из корня репозитория, Node.js 22 или новее:

```
node verify.cjs
node verify-rdw.cjs
```

## Публикация

Cloudflare Pages автоматически публикует `dist/` при отправке изменений в `main`.
Команда сборки: `node verify.cjs && node verify-rdw.cjs`.
Адрес: https://autobudget-nl.pages.dev/

Основной адрес и `*.autobudget-nl.pages.dev` защищены Cloudflare Access.
Вход — через Google; доступ определяется списком разрешённых email в политике Access.
OAuth-секрет хранится только в Cloudflare, не в репозитории.
GitHub Actions запускает проверки без публикации на GitHub Pages.

## Ограничения данных

MRB — бюджетная оценка, без провинциальных надбавок; точную квартальную сумму нужно перенести из калькулятора Belastingdienst. Страховка и расходы по умолчанию — сценарные допущения, не рыночные предложения. Поиск RDW показывает группы зарегистрированных машин, а не полный каталог коммерческих комплектаций. Недостающие характеристики явно отмечаются. Цена покупки и продажи задаётся пользователем.
